# Fault drills

Generated by `bun run drill`. Each drill runs the real worker processes, scheduler, analytics shipper and webhook deliverer against the provider simulator with injected faults, then judges the outcome from the simulator's request ledger, Postgres, ClickHouse and the simulator's answer key. Where a drill has a baseline, the same world and faults are run through the naive worker described in `src/drills/naive.ts` at the same concurrency.
